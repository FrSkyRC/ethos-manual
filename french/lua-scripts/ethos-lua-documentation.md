# Documentation d'Ethos Lua

La référence complète de l'API Lua d'Ethos est fournie avec **Ethos Suite**,
dans son onglet **Outils de développement Lua** — c'est la référence faisant
autorité pour chaque appel `system.*`, `lcd.*` et tous les autres appels d'API
disponibles pour un script, maintenue à jour avec la version d'Ethos avec
laquelle elle est distribuée.

Voir [Ethos Suite](../ethos-suite/index.md) pour l'installation et l'utilisation
de l'application PC elle-même.

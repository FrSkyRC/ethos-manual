Language differences:
1. They have their own radio backup files due to language setting
2. The Extra fwexample.bin models have different Timer names in DE, FR (Batterie) and ?
3. The DE model-select.lua has German category names, and scrolls down 4 to the Segler category
3a. The DE model-select deletes German folders created by it
4. zblank.bin calls up the zblank.md checklist file stored in each language radio backup
5. geronimo.md is called up by geronimo.bin in display
6. The EN wav files are copied to each language

To make other languages
-----------------------
A. Radio backup
1. Reload https://ethos.studio1247.com/nightly26/X20S_FCC?reset=all
2. Web Sim / Uploads 'Restore a radio backup' and select 'X20S_radio_backup.zip'
3. Go to System/General and set the display and audio language
4. Go to Timers and rename timer 1 to:
de Batterie
fr Batterie
5. Download radio backup
6. Unzip and add .md files 
6. Rename and zip
7. Add to github

B. For DE make a custom model-select and add to github
